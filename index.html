中转管理

按“入口端口 → 执行机器 → 目标服务”管理本机与 Agent 中转规则。

⇄
端口转发规则

规则会实际监听 绑定地址:监听端口，由本机面板或指定 Agent 转发至目标主机。支持 TCP、UDP 或同端口 TCP + UDP；可直接编辑、诊断并查看执行状态与流量。

入站管理

自动按协议生成可导入的 Xray 配置与分享链接。

◈
协议模板

支持 VLESS Reality、TCP、TLS、WebSocket + TLS、gRPC + TLS、Trojan TLS 与 Shadowsocks 2022。每项独立匹配配置模板；创建后会自动启动/重载本机 Core。请同时在云安全组和系统防火墙放行该节点端口。

用户管理

创建用户、设置配额与有效期，并可随时启停或删除。

◎
使用说明

此层负责用户档案和配额策略；节点客户端可在入站配置中按用户标识继续扩展。
