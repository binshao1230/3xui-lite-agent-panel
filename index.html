创建端口转发

创建后立即尝试绑定端口；若端口被占用或地址不可绑定，会显示异常原因。

导入 3x-ui 入站配置

支持 3x-ui 导出的单个 VLESS、Trojan 或 Shadowsocks 入站对象；保留原始 UUID、密码、Reality 私钥、传输和 TLS 字段。本机节点由本机 Core、远程节点由目标 Agent 在应用前校验；暂不可校验时会保留配置并显示异常。

部署 Agent

此命令适用于 Linux + systemd：会下载最新 Agent、创建常驻服务、设为开机启动并立即运行。执行时需要 sudo 权限；运行后令牌会写入目标机器权限为 0600 的 agent.env；部署命令本身包含可解码的敏感令牌，请勿分享或长期保存，泄露后请立即轮换。
